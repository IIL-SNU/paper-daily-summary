🔬 추천 연구주제

A. UltraVoxelGS의 feed-forward voxel-to-Gaussian 구조를 랩의 단면 스캔 영상에 이식

UltraVoxelGS는 2D 초음파 슬라이스를 고정 크기 voxel 지지대로 끌어올려 완전한 Gaussian 장면을 한 번에 예측하는 feed-forward 구조로, per-scene 최적화 대비 추론 속도를 10~20분에서 약 10초로 줄였습니다. OCT나 내시경처럼 역시 단면을 쌓아 3D를 복원하는 랩의 영상 양식에도 같은 구조가 통할 수 있습니다.

실행 1주차:

  • 대상 논문/코드: UltraVoxelGS (2611.11951) — 코드 공개, 공개 저장소 확인
  • 공통 benchmark: 랩 보유 단면 스캔 데이터셋(OCT 또는 내시경 시퀀스) 중 posed 영상 서브셋
  • 비교축: 기존 per-scene 최적화 3DGS 대비 feed-forward 추론 속도, PSNR/SSIM
  • 실패해도 남는 결과: feed-forward 예측이 랩 데이터에서 품질 저하를 보이더라도, 어떤 뷰 밀도·슬라이스 간격에서 품질이 무너지는지 정리한 실패 조건 목록은 다음 센서 설계에 재사용 가능하다.

B. SPECTRA의 스캐너/염색 강건 contrastive tuning을 랩 병리 파이프라인에 적용

SPECTRA는 같은 위치를 다른 스캐너·염색으로 찍은 짝을 대조학습으로 정렬하는 LoRA 어댑터로 PathoROB, HEST, CPTAC, PLISM 네 벤치마크 전부에서 강건성을 끌어올렸고, 어댑터와 가중치를 공개했습니다.

실행 1주차:

  • 대상 논문/코드: SPECTRA (2611.10093) — 공개 어댑터/가중치 확인
  • 공통 benchmark: 랩이 보유한 멀티스캐너 WSI/현미경 데이터(같은 조직을 다른 스캐너로 재촬영한 서브셋)
  • 비교축: 튜닝 전/후 임베딩 거리(스캐너 간), 다운스트림 분류 AUC의 스캐너 간 분산
  • 실패해도 남는 결과: 강건성 개선이 랩 데이터에서 재현되지 않더라도, 어느 스캐너 조합에서 임베딩 거리가 가장 크게 벌어지는지 정리한 진단은 데이터 수집 우선순위 결정에 재사용된다.

C. AgentCT의 손상 유형 분류 후 전문가 라우팅을 랩 복원 파이프라인에 이식

실행 1주차:

  • 대상 논문/코드: AgentCT (2611.11503) — 공개 코드 저장소 확인
  • 공통 benchmark: 랩이 다루는 2~3종 손상 유형이 섞인 고정 평가셋
  • 비교축: 단일 통합 복원 모델 대비 손상 분류+라우팅 구조의 PSNR/SSIM, 분류 정확도가 떨어질 때의 전체 성능 저하폭
  • 실패해도 남는 결과: 라우팅 구조가 이득이 없더라도, 손상 유형 분류기 자체의 혼동 행렬은 어떤 손상 쌍이 구분하기 어려운지 알려주는 진단 자료로 남는다.

UltraVoxelGS ↔ DPGS-SLAM — 둘 다 3D Gaussian Splatting을 쓰지만 "장면이 얼마나 안정적인가"에 대해 정반대 가정을 전제합니다. UltraVoxelGS는 정적인 조직을 빠르게 한 번에 훑어 feed-forward로 재구성하는 쪽(정적·단발)에 최적화돼 있고, DPGS-SLAM은 반대로 사람이나 물체가 계속 움직이는 환경에서 diffusion으로 가려진 부분을 채우며 지도를 꾸준히 갱신하는 쪽(동적·누적)에 최적화돼 있습니다. 둘을 나란히 보면, 3DGS 기반 의료/로보틱스 응용을 설계할 때 "한 번 훑어서 끝낼 정적 스캔인가, 계속 움직이며 갱신해야 하는 동적 관찰인가"가 구조 선택을 가르는 핵심 질문이라는 게 분명해집니다. 랩의 손 떨림이 섞인 현미경 스캔처럼 "거의 정적이지만 미세하게 흔들리는" 중간 영역에는 두 설계의 하이브리드가 필요할 수 있습니다.

[TIER A] AgentCT: A Vision-Language Agent for Universal CT Imaging — https://arxiv.org/abs/2611.11503

[방법전환] [평가축]

왜 A급인가: 오늘 "의료영상 역문제 복원이 물리 구조를 되살린다" 클러스터의 대표 논문이며, CT 복원에서 하나의 모델로 모든 손상을 처리하던 관행 자체를 "손상을 먼저 진단하고 전문가에게 보낸다"는 구조로 뒤집었다는 점, 그리고 그 효과를 9개 설정 전부에서 수치로 입증했다는 점에서 A급입니다.

핵심: 저선량 CT(LDCT), 희박뷰 CT(SVCT), 금속 아티팩트 보정(MAR)은 전부 "CT 복원"이라는 이름으로 묶이지만, 실제로는 서로 완전히 다른 물리적 손상(방사선량 부족, 투사 각도 부족, 금속으로 인한 신호 포화)입니다. 그런데도 최근 많은 연구가 이 셋을 하나의 범용 신경망으로 풀려고 시도해왔습니다. AgentCT는 이 가정을 깨고, LoRA로 가볍게 튜닝한 Qwen3-VL-4B 비전-언어 모델이 먼저 입력 영상을 보고 손상 종류와 심각도를 판별(정확도 95.7%/93.9%)한 뒤, 복원이 끝난 영상을 다시 평가해 필요하면 재조정하는 "컨트롤러" 역할을 합니다. 실제 복원은 손상별 전문 모델이 맡는데, LDCT는 이미지 도메인 diffusion 모델이, SVCT와 MAR은 투사 도메인 보정과 데이터 일관성, 미분 가능한 필터링 역투영(filtered back-projection), 영상 정제를 결합한 전용 파이프라인이 담당합니다. 환자가 겹치지 않도록 나눈 Mayo 2020 복부 CT 데이터에서, 정답 손상 라벨로 라우팅했을 때 AgentCT는 전체 PSNR/SSIM 46.18dB/0.984를 기록해 범용 모델 AMIR(44.93dB/0.976)과 TAMP(44.29dB/0.979)를 모든 9개 설정에서 앞질렀고, 특히 SVCT 전용 모델은 440만 개 파라미터만으로 46.04dB를 냈는데 이는 2350만 개 파라미터짜리 올인원 AMIR(43.57dB)보다도 높은 수치입니다. 랩의 관점에서 중요한 이유는, 랩이 다루는 영상 파이프라인에도 흔히 여러 종류의 손상(저조도, 모션 블러, 센서 결함 등)이 섞여 있을 텐데, 이를 하나의 범용 모델로 뭉뚱그리기보다 "먼저 진단하고 전문가에게 보내는" 구조가 더 적은 파라미터로 더 나은 성능을 낼 수 있다는 구체적 설계도를 제공하기 때문입니다.

주의: 보고된 최고 수치(46.18dB)는 정답 손상 라벨로 라우팅했을 때의 결과이며, 컨트롤러가 손상을 직접 분류해 자동으로 라우팅했을 때의 종단 간(end-to-end) 성능은 abstract에 별도로 명시되지 않아 본문에서 확인이 필요합니다. 또한 평가가 Mayo 2020 한 데이터셋에 한정돼 있어 다른 스캐너·병원 데이터에서도 같은 손상 분류 정확도가 유지되는지는 독립적인 검증이 필요합니다.

[TIER A] UltraVoxelGS: Voxel-First Feed-Forward Gaussian Splatting for 3D Ultrasound Reconstruction — https://arxiv.org/abs/2611.11951

[방법전환] [실사용전환]

왜 A급인가: 오늘 "3D Gaussian Splatting이 범용 3D 표현이 된다" 클러스터의 대표 논문이며, "품질과 속도 중 하나만 얻을 수 있다"던 3D 초음파 재구성의 오래된 트레이드오프를 feed-forward 구조로 동시에 깨, 스캔 도중 실시간 피드백이라는 실제 임상 워크플로우 변화를 만들어낸다는 점에서 A급입니다.

핵심: 2D 초음파 프로브를 손으로 움직이며 찍은 여러 단면 영상을 3D로 합치는 작업은 그동안 장면마다 처음부터 최적화를 새로 돌려야 해서 10~20분이 걸렸고, 이는 스캔하는 동안 실시간으로 결과를 확인할 수 없다는 뜻이었습니다. UltraVoxelGS는 자연 영상과 달리 초음파 단면들이 거의 겹치지 않고(기껏해야 1차원 교차선 공유) 초음파가 조직을 통과하며 감쇠되는 정도에 따라 같은 지점도 보는 각도마다 다르게 보인다는 점 때문에, 기존 feed-forward Gaussian 방법들이 가정하는 "촘촘한 뷰 중첩과 광도 일관성"이 통하지 않는다는 문제를 정면으로 다룹니다. 이를 풀기 위해 자세가 알려진 모든 단면들을 고정 크기 voxel 지지대로 끌어올린 뒤 그로부터 직접 Gaussian 파라미터를 예측하는 feed-forward voxel-to-Gaussian 변환을 도입해, 표현 크기가 입력 영상 개수에 끌려다니지 않게 만들었습니다. 또한 학습 중에는 반사와 누적 감쇠를 분리하고, 공간적으로 인접한 단면들 사이의 외관 연속성을 활용해 렌더링 시점에 외관을 빠르게 재조정하는 초음파 전용 렌더링 전략을 함께 제안합니다. 실제 임상 데이터와 시뮬레이션 데이터 양쪽에서, UltraVoxelGS는 장면마다 따로 최적화하는 기존 베이스라인과 동등하거나 더 나은 PSNR/SSIM을 내면서도 추론 시간을 10~20분에서 약 10초로(35배 이상) 줄였고, 1000프레임이 넘는 긴 시퀀스까지 그대로 확장됩니다. 랩의 관점에서 중요한 이유는, 단면을 쌓아 3D를 복원하는 영상 양식(OCT, 내시경, 현미경 z-스택 등)이라면 어디든 "실시간 피드백이 가능한 3D 표현"이라는 같은 요구가 있을 수 있고, 이 논문이 그 구조적 해법의 청사진을 제공하기 때문입니다.

주의: "베이스라인과 동등하거나 더 나은 PSNR/SSIM"이라는 표현은 구체적인 수치 차이를 abstract에서 밝히지 않아 본문의 정량 비교표를 확인해야 하며, 실시간 피드백이 실제로 임상의의 스캔 각도 결정에 도움이 되는지는 별도의 사용성 평가가 필요합니다.
