가장 뚜렷한 흐름은 Tomography/3D Imaging 버킷(56편) 안에서 feed-forward 3D Gaussian Splatting(3DGS) 논문 여섯 편이 과제를 다시 정의한 점입니다. GOFish는 기존 어안렌즈 3DGS 기법이 180도까지만 렌더링하고 메시를 못 만들던 한계를, 보정된 밀도화(densification)와 광각 외형 모델링으로 풀어 200도 이상 시야에서 메시까지 함께 뽑아냅니다. BudSplat과 GradSplat은 둘 다 feed-forward 3DGS가 장면별로 직접 최적화한 결과보다 품질이 떨어지는 문제를 다루는데, BudSplat은 렌더링 예산 제약 안에서 성능을 유지하는 쪽으로, GradSplat은 입력 이미지에 대한 그래디언트를 forward pass 안에서 직접 흘려보내 그 격차를 줄이는 쪽으로 접근합니다. SparseTokenGS와 EPC-RawDC, EUReCA는 모두 CT/CBCT라는 의료 영상 맥락에서 투영 수를 줄이면서도 재구성 품질을 지키는 문제를 다루고, Extremely Sparse-View CT는 아예 사전 재구성된 3D 볼륨 없이 2D 투영만으로 포즈 인식 diffusion prior를 학습시킵니다.

그 옆에서는 생성 모델과 자기지도 학습이 PET/CT/MRI 재구성 파이프라인에 직접 들어오는 흐름이 보였습니다. D-MOD는 가속 MRI 복원에서 diffusion posterior sampler가 여러 샘플을 평균 내야 안정적인 결과를 얻는 비효율을, 한 번에 posterior의 최빈값(mode)을 추정하는 방식으로 줄입니다. FFAI는 저선량·희소뷰·제한각 CT라는 서로 다른 촬영 조건을 하나의 flow matching 프레임워크로 묶어 재구성하고, LoRe-MIM은 PET/CT 라벨링 비용 문제를 마스킹 기반 자기지도 사전학습으로 우회하며, Accurate MRI-free PET Quantification은 MRI 없이 CT만으로 PET 정량화를 가능하게 하면서 conformal prediction으로 신뢰 구간까지 같이 냅니다. 계산광학 코어에서는 Fourier Ptychography/Microscopy 버킷에서 diffusion posterior sampling으로 ptychography의 측정 중복도 요구를 낮추는 논문이 실제 X선 데이터로 검증돼 눈에 띄었습니다(도메인 Watch Lens에서 자세히 다룹니다).

단일 가중치로 8~100장 투영을 모두 처리하는 feed-forward 구조가 랩 보유 sparse-view CT/CBCT 데이터에서도 기존 FDK 반복 재구성 대비 투영 수를 줄이면서 품질을 유지하는지 검증합니다.

실행 1주차:

  • 대상 논문/코드: EUReCA의 multiscale backbone + 3D transformer 디코더 구조 재구현
  • 공통 benchmark: 랩 보유 sparse-view CT/CBCT 데이터 + 기존 FDK/반복 최적화 베이스라인
  • 비교축: 8/20/50/100장 투영 조건별 PSNR, 재구성 시간, 뷰 수별 재학습 필요 여부
  • 실패해도 남는 결과: 랩 sparse-view 재구성 파이프라인의 feed-forward 전환 가능성 1차 진단

B. D-MOD의 posterior mode 추정을 랩 가속 MRI 복원 파이프라인에 이식

다중 샘플 평균 대신 minorize-maximize 기반 posterior mode를 한 번에 추정하는 방식이 랩 가속 MRI 데이터에서 재구성 품질을 유지하면서 추론 비용을 실제로 줄이는지 측정합니다.

실행 1주차:

  • 대상 논문/코드: D-MOD의 minorize-maximize posterior mode 추정 알고리즘 재구현
  • 공통 benchmark: 랩 보유 가속 MRI k-space 데이터 + 기존 diffusion posterior sampler(다중 샘플 평균) 베이스라인
  • 비교축: 동일 품질(PSNR/SSIM)에서 추론 시간, 샘플 수 대비 안정성
  • 실패해도 남는 결과: 랩 가속 MRI 파이프라인의 posterior sampling 비용 진단 보고서

C. 확률적 직교 정규화를 랩 learned-prior 복원망에 이식

Deep Projective Priors 훈련 손실에 확률적 직교 정규화를 추가하면 generalized projected gradient descent의 수렴 속도와 강건성이 실제로 개선되는지 랩 inverse-problem 파이프라인으로 검증합니다.

D. Progressive Coupling Diffusion Posterior Sampling을 랩 Fourier ptychography 파이프라인에 적용

스캔 중복도(overlap)를 줄여 촬영 속도를 높이면서도 diffusion prior로 복원 품질을 유지할 수 있는지, 랩 보유 ptychography 데이터로 검증합니다.

실행 1주차:

[TIER A] GOFish: Full Field-of-View Gaussian Splatting and Mesh Extraction — arXiv 2610.37818

[방법전환] [표준후보]

왜 A급인가: 오늘 클러스터1의 대표 논문이자, feed-forward 3DGS를 "빠른 렌더링"에서 "제약된 카메라에서도 버티는 복원기"로 바꾸는 흐름을 가장 구체적인 수치로 증명한 논문입니다.

핵심: 로봇·자율주행·360도 카메라는 넓은 시야를 보려고 어안렌즈를 쓰는데, 기존 어안렌즈용 3D Gaussian Splatting은 180도까지만 렌더링할 수 있었고 충돌 판정에 필요한 메시(mesh)도 만들지 못했습니다. 반대로 메시를 잘 뽑는 Gaussian surface reconstruction 기법들은 핀홀 카메라로 찍은 이미지만 가정해 어안렌즈에는 못 씁니다. GOFish는 "보정된 밀도화(calibrated densification)"로 시야 전체에 걸쳐 표면을 복원하고, "보정된 Mip 필터링"과 "광각 외형 모델링"으로 렌즈 특유의 흐림과 가장자리 밝기 저하가 장면과 메시에 섞여 들어가는 것을 막습니다. 그 결과 200도 FIORD와 205도 FullCircle 벤치마크에서 기존 최고 기법 대비 PSNR을 각각 2.28dB, 1.97dB 개선했고, 어안렌즈 전용 렌더링 기법들을 그들의 본래 시야각 안에서도 능가했으며, FIORD와 ScanNet++ 메인 세트에서 가장 높은 메시 F-score를 기록했습니다(abstract 기준). 랩이 로봇이나 360도 카메라로 디지털 트윈을 만드는 파이프라인을 다룬다면, LiDAR 없이 카메라만으로 실시간 렌더링과 충돌 지오메트리를 동시에 얻을 수 있다는 점에서 직접적인 실용적 의미가 있습니다.

주의: 200도 이상 극단적 광각에서 성능이 어디까지 유지되는지, 그리고 조명·질감이 복잡한 실내 환경에서도 메시 품질이 같은 수준인지는 abstract만으로는 확인되지 않아 본문 확인이 필요합니다.

[실사용전환] [인프라]

왜 A급인가: 오늘 클러스터1의 대표 논문이자, feed-forward 3DGS 계열 연구 중 유일하게 실제 환자 스캔 15건으로 검증까지 마친 임상 수준 결과입니다.

핵심: 콘빔 CT(CBCT)는 영상유도 방사선치료에 널리 쓰이지만, 방사선량과 스캔 시간을 줄이려고 투영 수를 줄이면 재구성이 점점 풀기 어려운 문제가 됩니다. EUReCA는 8~100장이라는 넓은 범위의 투영 수를 단 하나의 가중치 세트로 처리하는 feed-forward 모델로, 투영 수가 바뀔 때마다 재학습할 필요가 없고 다른 임상 촬영 궤적에도 구조 변경 없이 그대로 적용됩니다. 각 투영을 공유 멀티스케일 백본으로 인코딩하고, 촬영 기하 정보를 이용해 특징을 멀티해상도 3D 격자에 역투영한 뒤, 전역 3D 트랜스포머와 다단계 디코더로 볼륨을 정제합니다. 시뮬레이션에서는 10~100장 투영 조건 전체에서 29.9~33.2dB PSNR을 기록해 다른 feed-forward 베이스라인을 모두 능가했고, 반복 최적화 기반 기존 방법보다도 품질이 높으면서 속도는 훨씬 빨랐습니다. 실제 환자 CBCT 스캔 15건을 벤더 재구성 결과와 비교했을 때도 모든 테스트 투영 수 조건에서 최고 성능을 기록했습니다(abstract 기준). 랩이 CT/CBCT 재구성을 다룬다면, "투영 수마다 다른 모델"이 아니라 "하나의 모델이 여러 투영 수를 커버"한다는 설계가 바로 참고할 만합니다.

주의: 실제 환자 데이터 검증이 15건으로 비교적 소규모이고, 어떤 스캐너 제조사·치료 부위에서 검증됐는지 abstract에 구체적으로 명시되지 않아 더 넓은 기관·장비로 일반화되는지는 본문 확인이 필요합니다.

[TIER A] D-MOD: Diffusion mode estimation for accelerated MRI — arXiv 2610.40110

[방법전환] [실사용전환]

왜 A급인가: 오늘 클러스터2의 대표 논문이자, diffusion 기반 MRI 복원의 오래된 실용성 문제(샘플을 여러 번 뽑아야 안정적이다)를 정면으로 겨냥한 논문입니다.

핵심: 가속 MRI 복원에서 diffusion 모델은 강력한 prior로 쓰이지만, 대부분의 방법이 posterior에서 무작위로 하나의 결과를 뽑는 posterior sampler입니다. 재현 가능하고 품질 좋은 복원을 얻으려면 여러 샘플을 뽑아 평균을 내야 하는데, 이는 계산 비용을 크게 늘립니다. D-MOD는 샘플을 여러 번 뽑는 대신 posterior의 최빈값(mode)을 한 번에 추정하는 빠른 알고리즘입니다. minorize-maximize 방식을 써서 반복적으로 하한을 최적화하는 방식으로 mode를 찾습니다(abstract 기준). 랩이 가속 MRI나 다른 역문제에 diffusion posterior sampling을 쓰고 있다면, 다중 샘플 평균 대신 D-MOD 방식의 단일 추론으로 바꿨을 때 품질 저하 없이 추론 비용을 줄일 수 있는지가 바로 확인해볼 만한 질문입니다.

주의: mode 추정이 기존 다중 샘플 평균 대비 구체적으로 몇 배 빠른지, 그리고 어떤 언더샘플링 비율까지 안정적인지는 abstract에 정량 수치가 많지 않아 본문 확인이 필요합니다.
