SSD/VGG16 기반 hotspot 검출과 좌표 변환 registration 파이프라인을 랩의 반도체/재료 결함 검사용 현미경 자동화 도구에 적용해, 분석 시간과 분석자 간 일관성을 동시에 개선할 수 있는지 확인합니다.

실행 1주차:

  • 대상 논문/코드: Automated End-to-End AI Solution for Photon Emission Microscopy 워크플로우 재현
  • 공통 benchmark: 랩 보유 결함 검사 현미경 이미지 세트(reference vs target 쌍)
  • 비교축: 기존 수작업 분석 시간 대비 자동화 파이프라인 처리 시간, hotspot 분류(same/extra/missing) 정확도
  • 실패해도 남는 결과: 랩 결함 검사 워크플로우의 수작업 병목 구간 정량 분석

C. KAN 기반 single-instance prior PnP를 랩 렌즈리스 위상 복원에 적용

외부 학습 데이터셋 없이 단일 촬영 이미지 안에서만 사전 정보를 추출하는 KAN 기반 Plug-and-Play 방법을 랩의 학습 데이터가 부족한 새 광학계 프로토타입에 적용해, 재학습 없이도 합리적인 복원 품질을 얻을 수 있는지 확인합니다.

실행 1주차:

  • 대상 논문/코드: You KAN do it in a Single Shot 방법 재현
  • 공통 benchmark: 랩 보유 신규 광학계 프로토타입(학습 데이터셋 미구축 상태)의 단일 촬영 데이터
  • 비교축: 기존 학습 기반 PnP 대비 단일 촬영 복원 품질(SSIM/PSNR), 필요 사전 데이터량
  • 실패해도 남는 결과: 랩 신규 광학계에서 single-instance prior가 유효한 조건과 무효한 조건 정리

D. GA-PCT의 line-structured light+지연 샘플링 결함 깊이 분석을 랩 비파괴검사 파이프라인에 적용

갈바노미터 기반 line-structured light 스캐닝과 지연 샘플링을 결합한 광열 코히런스 단층촬영 방식을 랩의 비파괴검사/현미경 결함 탐지 파이프라인에 적용해, 표면과 내부 결함을 동시에 3차원으로 정량화할 수 있는지 확인합니다.

  • 대상 논문/코드: Geometry Adaptive Photothermal Coherence Tomography 워크플로우 재현

[TIER A] Unambiguous thin-film thickness measurement using phase disambiguation in Fresnel diffraction from a phase step — Journal of Optics

[방법전환] [표준후보]

왜 A급인가: 랩이 다루는 위상 이미징·박막 계측 문제는 위상이 2π마다 반복돼서 생기는 모호성 때문에 두께 측정 범위가 제한되는 경우가 많은데, 이 논문은 그 모호성 자체를 정면으로 겨냥해 50~2000nm라는 넓은 범위에서 1nm 이하 오차를 달성했습니다. 연속적인 각도 스캐닝이나 visibility 카운팅 없이도 되는 실용적인 접근이라 랩 계측 파이프라인에 바로 참고할 수 있습니다.

핵심: 반사형 위상 계단에서 나오는 Fresnel 회절 프로파일이 두께·파장·입사각에 따라 주기적으로 반복되는 문제를, 세 개의 서로 다른 입사각(단일 파장) 또는 세 개의 서로 다른 파장(고정 입사각)에서 얻은 후보 두께 집합을 겹쳐서 교집합으로 좁히는 방식으로 해소합니다. Angular Spectrum 방법으로 전체 회절 강도 프로파일을 피팅해 두께를 결정하며, 두 방식(다각도/다파장) 모두 0.5~1nm 수준의 일치도를 보였습니다.

주의: 실험이 반사형 위상 계단이라는 특정 기하 조건에 한정돼 있어, 랩이 다루는 투과형 또는 곡면 위상 샘플에도 그대로 적용되는지는 본문 확인이 필요합니다. 다중 각도/파장 측정에 필요한 추가 촬영 시간이 abstract에 나오지 않아 실시간 적용 가능성도 별도 검증이 필요합니다.

[TIER A] Automated End-to-End AI Solution for Photon Emission Microscopy in Semiconductor Failure Analysis — EDFA Technical Articles

[실사용전환] [인프라]

왜 A급인가: 계산 이미징 기법을 실제 산업 현장에 배포했을 때 어떤 정량적 이득이 나오는지를 드물게 구체적인 수치로 보여주는 논문입니다. 반도체 소자가 점점 미세화되면서 사람이 눈으로 결함 위치를 판독하던 기존 방식이 한계에 부딪히는 상황에서, 이 논문은 딥러닝 자동화가 실제로 분석 시간을 80% 이상 줄인다는 것을 내부 평가로 확인했습니다.

핵심: 수만 장의 raw/overlay PEM 이미지를 hybrid auto-seeding/전문가 큐레이션 방식으로 라벨링해 학습시킨 SSD/VGG16 모델이 여러 배율에서 hotspot(결함 의심 지점)을 검출하고, registration 기반 비교 파이프라인이 기준 이미지와 대상 이미지 사이의 hotspot을 same/extra/missing으로 분류하며, 좌표 변환 시스템이 Avalon 레이아웃 데이터베이스와 SSH로 연동해 자동으로 해당 회로 인스턴스를 불러옵니다. 이 모든 기능이 하나의 GUI로 통합돼, 분석 시간이 약 30분에서 몇 분으로 줄었습니다.

주의: "80% 이상 단축"이라는 수치가 내부 평가(internal evaluation) 기준이라 외부 벤치마크나 다른 반도체 공정에서도 재현되는지는 확인이 필요합니다. 학습에 쓴 라벨링 전략(auto-seeding+전문가 큐레이션)의 초기 라벨링 비용이 abstract에 나오지 않아, 랩이 유사 파이프라인을 구축할 때 필요한 초기 투자 규모는 별도로 가늠해야 합니다.

  • Deep Learning Methods 15편 중 이미징과 결이 다른 12편 — 뇌종양 세그멘테이션, 하이퍼스펙트럴 분류, 다발성 골수염 감별진단 등 의료영상 인접 분야이거나, USV 경로계획·리간드 스크리닝처럼 완전히 무관한 응용입니다.
  • Fourier Ptychography/Microscopy 2편, Lensless/Coded Imaging 1편 [JNL] — SAR 레이더·자기입자영상(MPI)으로 광학 계산 이미징과 무관한 키워드 오탐입니다.
