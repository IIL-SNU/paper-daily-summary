📐 arXiv(방법) vs 저널(응용) 대비

오늘은 이 대비가 유난히 한쪽으로 쏠린 날입니다. arXiv 쪽(cs.LG/cs.CV/cs.AI/eess.IV/eess.SP)에서는 "world model", "physics-aware", "agentic", "grounding", "report alignment"처럼 방법론 중심 키워드가 오늘 네 클러스터 전부를 채웠고, 저널(Crossref/OpenAlex) 쪽은 그중 어느 클러스터에도 직접 짝이 되는 응용 신호를 내지 못했습니다. 계산광학 핵심 ROI에서는 반대로 저널 쪽이 거의 모든 신호를 냈습니다 — FPM pupil self-calibration 논문(JNL), lensless Swin Transformer 복원 논문(JNL), femtosecond X-ray 위상 대비 영상 논문(JNL)이 그렇습니다. 공통 키워드는 "world model"과 "reconstruction"인데, arXiv의 world model은 로봇 조작·의료 초음파 시뮬레이션처럼 행동-조건부 생성을 가리키고, 저널의 reconstruction은 FPM·lensless처럼 고정된 광학 하드웨어의 계산 보정을 가리켜 같은 단어가 가리키는 대상의 범위가 다릅니다. 즉 오늘은 "일반 ML 방법은 arXiv, 계산광학 하드웨어 응용은 저널"이라는 평소 분업이 특히 또렷했고, 동시에 계산광학 핵심 ROI 저널 신호 자체가 평소보다 얇아 이 대비 구조가 "풍성한 쌍"보다는 "서로 다른 방에서 각자 일하는 모습"에 가까웠습니다.

💡 오늘의 인사이트

1. World model이 그럴듯한 영상보다 물리·해부학 법칙을 실제로 지키는지로 평가받기 시작

Confidence: High

Refrain은 CLIP/DINO 같은 기존 유사도 지표가 의도된 장면 전환을 일관성 붕괴로 잘못 판단한다는 걸 보이고 이를 보정하는 지표를 제안했는데, 랩이 쓰는 PSNR/SSIM류 지표도 의도된 콘텐츠 변화(예: 시료 자체의 시간적 변화)와 복원 실패를 구분하지 못하고 있는지 재검토할 가치가 있습니다.

실행 1주차:

  • 대상 논문/코드: Refrain (arXiv 2611.27806) — 코드 공개 여부 본문 확인 필요

[TIER A] Non-penetrating World Models

[경고신호] [평가축]

왜 A급인가: world model 연구가 지금까지 당연하게 넘겨온 가정 하나 — "그럴듯한 영상을 만들면 충분하다" — 를 정면으로 반박하고, 공개된 모델 전부가 물리적으로 불가능한 장면을 걸러내지 못한다는 걸 보이면서도, 그 문제를 고치는 방법까지 같은 논문에서 매우 가볍게(작은 head 하나) 제시했다는 점에서 A급입니다. 문제를 "드러내기만" 한 게 아니라 "거의 공짜로 고칠 수 있다"는 걸 같이 보여준 드문 사례입니다.

핵심: 로봇 조작이나 시뮬레이션에 쓰이는 interactive video world model(사용자의 행동에 따라 영상이 어떻게 바뀔지 예측하는 생성 모델)은 물리적으로 불가능한 일 — 예를 들어 손이 상자를 뚫고 지나가는 장면 — 을 방지해야 하는데, 이 논문은 이를 직접 측정하는 NoPeBench라는 벤치마크를 먼저 만듭니다. 측정 결과 공개된 여러 world model 전부가 이런 물리 위반을 안정적으로 막지 못했습니다. 그런데 저자들은 여기서 멈추지 않고, "모델이 이 위반을 예측하지 못하는 걸까, 아니면 알면서도 못 막는 걸까"를 확인합니다. 놀랍게도 diffusion transformer(여러 단계를 거쳐 영상을 생성하는 트랜스포머 기반 생성모델)의 숨은 상태(hidden state)만 봐도 "이 후보 행동이 물리를 어길지"를 상당히 정확하게 예측할 수 있었습니다. 즉 모델은 이미 필요한 정보를 갖고 있는데, 그 정보를 행동 결정에 쓰지 않고 있었을 뿐입니다. 저자들은 이 숨은 상태 위에 작은 예측 head 하나를 학습시켜 "이 후보 행동이 안전한지"를 읽어내고, 위험한 행동은 원래 의도를 최대한 보존하는 안전한 행동으로 바꿔치기하는 NoPeWorld 프레임워크를 만들었습니다. 그 결과 여섯 개 world model 평균 물리 위반율이 74%에서 16%로 떨어졌고, 놀랍게도 전혀 다른 도메인의 이미지, 3인칭 시점, 움직이는 장애물에도 추가 학습 없이 바로 적용됐습니다(zero-shot 일반화).

약점: 16%로 낮아졌어도 완전히 0은 아니라서, 안전이 절대적으로 중요한 로봇 배포 환경에서 이 정도 잔여 위반율이 허용 가능한 수준인지는 abstract만으로 판단하기 어렵습니다. 또한 "물리 위반"의 정의가 NoPeBench가 설계한 장애물-관통 시나리오에 한정돼 있어, 랩이 다루는 광학적 비현실성(예: 불가능한 굴절, 위상 불연속)에도 같은 탐지 방식이 통하는지는 본문·재현 확인이 필요합니다.

우리 랩 파이프라인 영향: 랩이 생성형 복원/시뮬레이션 모델을 쓰는 모든 지점(특히 diffusion 기반 역문제 솔버)에서, 복원 결과가 물리적으로 불가능한 구조(음수 굴절률, 불가능한 겹침, 위상 불연속)를 만들어내는지 frozen 모델의 내부 상태만으로 사후 검증할 수 있다는 아이디어를 바로 시도해볼 수 있습니다.

[TIER A] One state, many questions: Opsis gives a frontier model typed eyes for pathology

[방법전환] [표준후보]

왜 A급인가: "거대 멀티모달 모델에게 영상을 보여주고 질문하면 된다"는, 최근 의료 영상 AI에서 가장 흔한 접근 하나를 정면으로 반박하고, 그 접근이 왜 구조적으로 실패할 수밖에 없는지(문맥 창 한계)를 먼저 밝힌 뒤 아주 단순한 대안(질문 인터페이스)만으로 정답률을 다수결 수준 아래에서 최고 수준까지 끌어올렸다는 점에서 A급입니다.

핵심: 병리 보고서는 "이 조직이 어떤 유형인가" 같은 정해진 답 후보를 가진 질문들의 체크리스트에 가깝고, 그중 상당수는 다른 질문들의 답을 조합해서 풀립니다(복합 질문). 지금까지는 각 질문마다 따로 라벨을 붙여 학습시킨 전용 분류기가 정확했지만 질문을 자유롭게 조합하지 못했고, 자유롭게 조합할 수 있는 거대 언어모델은 슬라이드 하나가 1만 4천 개 조각 이미지로 구성돼 모델의 문맥 창에 다 넣을 수 없다는 근본적인 한계가 있었습니다. 실제로 유방암 보고서 질문 189개에서, 모델이 미리 적힌 설명을 읽거나 슬라이드 축소본과 몇 개 조각만 보고 답하면 정답률이 0.50~0.66으로 다수결(0.67)보다도 낮았습니다. Opsis는 이 문제를 "모델이 슬라이드를 직접 보게" 하는 대신 "모델이 슬라이드에게 직접 묻게" 하는 쪽으로 뒤집습니다 — 슬라이드를 한 번만 인코딩해 두고, 질문이 연산자·인자·후보를 지정하면 그 인코딩 위에서 확률 답을 돌려주는 타입이 있는 질의 인터페이스(Opsis)를 frozen Virchow2 토큰 위에 1천만 파라미터짜리 작은 디코더로 구현했습니다. 그 결과 네 개의 frontier 모델이 Opsis에게 물어서 답하는 방식으로 유방암 질문 정답률이 0.78~0.79로 뛰었고, 범암종 질문 3,797개에서는 직접 보는 방식보다 8.6점 높았습니다. 학습한 적 없는 995개의 복합 질문에서도, frontier 모델이 Opsis의 답을 조합해 0.76을 냈는데 이는 슬라이드를 직접 보는 0.69보다 높고, 그 복합 질문 전용으로 학습한 분류기(0.78)에 근접했습니다.

약점: Opsis의 성능은 결국 기반이 되는 frozen 병리 인코더(Virchow2)의 품질에 의존하므로, 더 약한 인코더에서도 같은 개선폭이 나오는지는 abstract만으로 알 수 없습니다. 또한 유방암·범암종 질문 체계가 TCGA 기반으로 구성돼 있어, 랩이 접하지 않는 희귀 조직이나 다른 염색 프로토콜에서도 같은 질의 인터페이스 설계가 통하는지는 본문 확인이 필요합니다.

우리 랩 파이프라인 영향: 랩이 거대 멀티모달 모델로 복원 결과나 측정 데이터를 해석하게 할 때, "전체를 설명해줘"라고 묻는 대신 "이 구조가 있는가/어디에 있는가"처럼 타입이 있는 질문으로 바꾸는 것만으로 해석 신뢰도를 끌어올릴 수 있다는 구체적인 설계 패턴을 제공합니다.

  • Tomography/3D Imaging 순수 임상/법의학 증례 약 11편 — 치과 CBCT 증례, 관상동맥 CTA, 요통 MRI 평가 등 CT/MRI를 "사용"하지만 영상 재구성 방법론에는 기여하지 않는 순수 응용 연구입니다.
  • Reconstruction/Inverse Problems 임상/일반 ML 약 14편 — 교통신호 제어, 금융 시계열, 연합학습 클러스터링 등 이미징과 직접 관련 없는 일반 역문제 응용입니다.
  • Phase Imaging/Holography 완전/부분 무관 3~4편 — 플라즈마 제트 다중시점 진단, 디스플레이 홀로그래피 리뷰, 전자 홀로그래피 리뷰(둘 다 abstract 없음) 등 랩 ROI와 응용이 거리가 있는 논문입니다.
  • Deep Learning Methods 127편 대부분 — 트래픽 신호 제어, 금융 딥러닝, 양자 정보, IoT 침입 탐지 등 전산 광학 이미징과 직접 관련이 없는 범용 ML·공학 응용입니다.

World model의 물리·해부학 일관성 (5편)

Non-penetrating World Models CV
문제: world model이 로봇 행동 결과로 물리적으로 불가능한 장면(장애물 관통)을 만들어내도 이를 방지하는 장치가 없음 / 방법: NoPeBench로 위반율을 먼저 측정하고, frozen diffusion transformer의 숨은 상태 위에 작은 예측 head를 학습시켜 위험 행동을 안전 행동으로 대체 / 의미: 여섯 개 모델 평균 위반율 74%→16%, zero-shot으로 다른 도메인에도 일반화 / 우선순위: Must-read
PhysForce CV
문제: 힘 개입을 움직임 궤적으로만 가르치면 모델이 외운 움직임 패턴에 의존해 실제 물리 반응을 배우지 못함 / 방법: 힘의 위치·방향·크기를 잠재 표현에 직접 주입하고 그 반응이 어디서 일어나야 하는지를 별도 네트워크로 연결, 강화학습으로 분포 밖 상황까지 일반화 / 의미: 힘 반응성·물리적 일관성·일반화 모두 개선 / 우선순위: Read
ViewDreamer CV
문제: 로봇마다 카메라 수·배치가 달라 기존 world model이 시점별로 따로 생성하거나 고정 레이아웃에 의존 / 방법: 시점 간 공유 슬롯 토큰으로만 소통하게 하는 커리큘럼 학습 / 의미: RoboView-Bench에서 최고 품질, world-action model 성공률도 함께 향상 / 우선순위: Read
SonoAtlasWorld CV
문제: 초음파 world model이 탐촉자 행동과 영상 이력만으로는 넓은 범위 스캔에서 해부학적 일관성을 유지하지 못함 / 방법: CT에서 뽑은 3D 해부학 자산을 상태로 고정하고 인과적 변환·장기 롤아웃 정렬을 단계적으로 학습 / 의미: AFI 0.428(비교 방법 최대 0.117), 정책 학습 성공률 48.2%→81.2% / 우선순위: Must-read
SOAR CV
문제: latent world model의 계획이 수백 개 후보 행동을 롤아웃해야 해서 결정 하나에 수십 초가 걸림 / 방법: 각 결정마다 몇 개 후보로 토큰 예산을 미리 시험해 순위가 유지되는 최소 예산만 선택 / 의미: 2.3배 가속에서 dense 수준 성공률, 2.5배에서도 98% 유지 / 우선순위: Read

영상 생성의 멀티샷/멀티뷰 일관성 (4편)

Refrain CV
문제: 스타일이 다른 여러 참고 이미지를 섞어 일관된 멀티샷 영상을 만들기 어렵고, 기존 평가 지표가 의도된 컷 전환을 오탐 / 방법: 같은 원본 영상의 참고 클립을 의도적으로 편집해 복원시키는 자기지도 재구성 과제 / 의미: 실제 영상의 스타일 변화 통계를 기준선으로 삼는 Shot-Debiased Consistency 지표 제안, 교차샷 일관성 SOTA / 우선순위: Read
Hindsight Forcing CV
문제: 스트리밍 영상 생성에서 이전 조각이 이후 생성에 어떻게 도움이 되는지 피드백을 받지 못해 화질이 점점 무너짐 / 방법: 미래 손실의 기울기를 과거의 특정 생성 단계로 거꾸로 연결하는 latent straight-through bridge / 의미: 추가 파라미터 없이 VBench 품질·동적 움직임 개선 / 우선순위: Read
GameScrub CV
문제: 게임 HUD 제거 학습이 인위적으로 합성한 쌍에 의존해 실제 HUD의 40~50%를 못 지움 / 방법: 실제 녹화 영상에서 HUD 영역을 diffusion 인페인팅으로 복원해 학습 쌍 직접 생성 / 의미: 제거 점수 57.86→71.95, HUD 요소 제거율 59.07%→90.06% / 우선순위: Read
Ego2Ego CV
문제: 내 시점에서 협업자 시점 영상을 생성하는 문제는 극단적 시점 차이와 가림으로 기존 방법이 다루지 못함 / 방법: 공유 3D 장면 좌표를 모든 시점에 렌더링해 디퓨전 모델의 공간 참조로 사용 / 의미: 세 개 백본 전부에서 품질·장면배치 정확도·협업자 움직임 개선 / 우선순위: Read
